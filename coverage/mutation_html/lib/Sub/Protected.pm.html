  130: =head1 DESCRIPTION
  131: 
  132: Enforces Java/C++-style "protected" access at runtime: a subroutine
  133: decorated with C<:Protected> (or named in C<use Sub::Protected qw(...)>)
  134: may only be called from within its defining package or from a subclass of
  135: that package.  Any other caller causes a C<Carp::croak> with a descriptive
  136: message.
  137: 
  138: =head2 Two usage forms
  139: 
  140: =over 4
  141: 
  142: =item Attribute form (preferred)
  143: 
  144:     sub _helper :Protected { ... }
  145: 
  146: The C<:Protected> attribute is registered in C<UNIVERSAL> via
  147: L<Attribute::Handlers> when C<Sub::Protected> is loaded, so every package
  148: has access to it without any further C<use> or inheritance.  The sub is
  149: wrapped at C<CHECK> time, or, if the module is loaded after C<CHECK> (Perl
  150: 5.14 or later), at the end of the file being compiled.  This form is preferred because the protection
  151: declaration sits next to the definition and wrapping happens at compile time
  152: (making pre-wrap raw-coderef captures impossible).
  153: 
  154: =item Declarative form
  155: 
  156:     use Sub::Protected qw(_helper _other);
  157: 
  158: Each named sub is looked up in the caller's stash and wrapped at C<CHECK>
  159: time (or immediately if the module is loaded at runtime via C<require>).
  160: All named subs must be defined before C<CHECK> fires -- i.e. they must be
  161: compile-time named subs in the same file, not generated at runtime.
  162: 
  163: =back
  164: 
  165: =head2 Bypass for testing
  166: 
  167: Either condition alone (OR logic) disables all access checks:
  168: 
  169: =over 4
  170: 
  171: =item * C<$Sub::Protected::BYPASS> set to a true value.  Use C<local> in tests.
  172: 
  173: =item * C<$ENV{HARNESS_ACTIVE}> set (the convention used by L<Test::Harness>/prove).
  174: 
  175: =back
  176: 
  177: C<$Sub::Protected::BYPASS> is the recommended form for new test code;
  178: it is explicit and does not depend on the test runner.
  179: C<HARNESS_ACTIVE> is a zero-config convenience.
  180:

  567: =head1 KNOWN LIMITATIONS
  568: 
  569: =over 4
  570: 
  571: =item Runtime-only
  572: 
  573: Checks are runtime only; there is no compile-time enforcement.
  574: 
  575: =item Raw coderef bypass
  576: 
  577: A raw code reference obtained B<before> wrapping (via C<can()> or direct
  578: C<\&Foo::_helper>) bypasses the check.  The attribute form prevents this
  579: because wrapping happens at compile time.
  580: 
  581: =item Moo/Moose method modifiers
  582: 
  583: Method modifiers applied after Sub::Protected has wrapped a sub will wrap
  584: the wrapper.  Apply Sub::Protected last, or use the declarative form in a
  585: C<CHECK> block after the class is fully built.
  586: 
  587: =item Run-time loading on Perl < 5.14
  588: 
  589: On Perls older than 5.14, loading this module (or a package that uses it)
  590: at run time -- via C<require>, a plugin loader or a string C<eval> -- leaves
  591: the subs unprotected, because C<CHECK> has already fired.  Load it at
  592: compile time instead.
  593: 
  594: =item UNIVERSAL namespace pollution
  595: 
  596: The C<:Protected> attribute is installed in C<UNIVERSAL>, which is
  597: intentional (any package can use it after a single C<use>), but it does
  598: introduce C<UNIVERSAL::Protected> into the global namespace.
  599: 
  600: =item Thread safety
  601: 
  602: C<@_pending> and C<$BYPASS> are unguarded package globals.  Do not use
  603: concurrent C<use Sub::Protected qw(...)> calls across threads.
  604: 
  605: =back

  638: =head1 FORMAL SPECIFICATION
  639: 
  640: =head2 import
  641: 
  642: The following Z-notation schemas formally specify the state and operations
  643: of Sub::Protected.  Unicode mathematical symbols are used in this section
  644: only.
  645: 
  646:     -- Type abbreviations
  647:     Package  == seq CHAR     -- a non-empty Perl package name string
  648:     SubName  == seq CHAR     -- a Perl identifier string
  649:     Proc     == seq CHAR     -- abstract: a callable code reference
  650: 
  651:     -- Ancestry relation (derived dynamically from @ISA chains)
  652:     anc : Package -> P Package
  653:     forall p : Package .
  654:         anc p = {p} union bigcup { anc r | r in @ISA_of(p) }
  655: 
  656:     -- Protected-access predicate
  657:     permitted : Package x Package -> BOOL
  658:     forall caller, owner : Package .
  659:         permitted(caller, owner) <=> owner in anc(caller)
  660: 
  661:     -- System state
  662:     +-Registry-------------------------------------------+
  663:     | protected : P (Package x SubName)                  |
  664:     | bypass    : BOOL                                   |
  665:     | config    : { harness_bypass : BOOL }              |
  666:     +----------------------------------------------------+
  667: 
  668:     -- Initial state
  669:     +-InitRegistry---------------------------------------+
  670:     | Registry                                           |
  671:     |----------------------------------------------------|
  672:     | protected = {}                                     |
  673:     | bypass    = false                                  |
  674:     | config    = { harness_bypass |-> true }            |
  675:     +----------------------------------------------------+
  676: 
  677:     -- Wrap: add a sub to the protected registry
  678:     +-Wrap-----------------------------------------------+
  679:     | Delta-Registry                                     |
  680:     | pkg? : Package ; name? : SubName                   |
  681:     |----------------------------------------------------|
  682:     | protected' = protected union { (pkg?, name?) }     |
  683:     | bypass'    = bypass                                |
  684:     | config'    = config                                |
  685:     +----------------------------------------------------+
  686: 
  687:     -- Bypass predicate
  688:     bypass_active(R) <=>
  689:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  690: 
  691:     -- Access check: no state change
  692:     +-CheckAccess----------------------------------------+
  693:     | Xi-Registry                                        |
  694:     | caller? : Package                                  |
  695:     | owner?  : Package                                  |
  696:     | name?   : SubName                                  |
  697:     | ok!     : BOOL                                     |
  698:     |----------------------------------------------------|
  699:     | (owner?, name?) in protected                       |
  700:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  701:     +----------------------------------------------------+
  702: 
  703:     -- Violation (croak case):
  704:     --   not ok! =>
  705:     --   croak("name?()" ++ " is a protected method of " ++ owner?
  706:     --         ++ " and cannot be called from " ++ caller?)
