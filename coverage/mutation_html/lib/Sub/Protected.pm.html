  210: =head1 DESCRIPTION
  211: 
  212: Enforces Java/C++-style "protected" access at runtime: a subroutine
  213: decorated with C<:Protected> (or named in C<use Sub::Protected qw(...)>)
  214: may only be called from within its defining package or from a subclass of
  215: that package.  Any other caller causes a C<Carp::croak> with a descriptive
  216: message.
  217: 
  218: =head2 Two usage forms
  219: 
  220: =over 4
  221: 
  222: =item Attribute form (preferred)
  223: 
  224:     sub _helper :Protected { ... }
  225: 
  226: The C<:Protected> attribute is registered in C<UNIVERSAL> via
  227: L<Attribute::Handlers> when C<Sub::Protected> is loaded, so every package
  228: has access to it without any further C<use> or inheritance.  The sub is
  229: wrapped at C<CHECK> time.  This form is preferred because the protection
  230: declaration sits next to the definition and wrapping happens at compile time
  231: (making pre-wrap raw-coderef captures impossible).
  232: 
  233: =item Declarative form
  234: 
  235:     use Sub::Protected qw(_helper _other);
  236: 
  237: Each named sub is looked up in the caller's stash and wrapped at C<CHECK>
  238: time (or immediately if the module is loaded at runtime via C<require>).
  239: All named subs must be defined before C<CHECK> fires -- i.e. they must be
  240: compile-time named subs in the same file, not generated at runtime.
  241: 
  242: =back
  243: 
  244: =head2 Bypass for testing
  245: 
  246: Either condition alone (OR logic) disables all access checks:
  247: 
  248: =over 4
  249: 
  250: =item * C<$Sub::Protected::BYPASS> set to a true value.  Use C<local> in tests.
  251: 
  252: =item * C<$ENV{HARNESS_ACTIVE}> set (the convention used by L<Test::Harness>/prove).
  253: 
  254: =back
  255: 
  256: C<$Sub::Protected::BYPASS> is the recommended form for new test code;
  257: it is explicit and does not depend on the test runner.
  258: C<HARNESS_ACTIVE> is a zero-config convenience.
  259: 
  260: The HARNESS_ACTIVE bypass can be disabled by setting:

  546: # _assert_private_caller
  547: # Purpose:    Croak if the guarded private method was called from outside
  548: #             Sub::Protected (or a subclass).  Used to enforce visibility.
  549: # Entry:      ($method_name) -- name of the guarded method, used in the message.
  550: #             Must be called directly (not nested deeper) inside the guarded method.
  551: # Exit:       Returns normally if the caller is Sub::Protected or a subclass.
  552: #             Croaks with a descriptive message otherwise.
  553: # Side effects: Calls Carp::croak on failure.
  554: # Notes:      caller() semantics from inside this sub:
  555: #               caller(0) -- the package in which the call TO this sub was made.
  556: #                            That is the guarded method's package = Sub::Protected.
  557: #               caller(1) -- the package in which the call TO the guarded method
  558: #                            was made.  That is the actual external caller to check.
  559: sub _assert_private_caller {
  560: 	my ($method_name) = @_;
  561: 
  562: 	# caller(1): the package that invoked the guarded method directly.
  563: 	my $caller = (caller(1))[0] // q{};
  564: 	return if $caller eq $SELF || eval { $caller->isa($SELF) };
  565: 
  566: 	croak "${method_name}() is a private method of $SELF"
  567: 		. " and cannot be called from ${caller}";
  568: }
  569: 
  570: 1;
  571: 
  572: __END__

  574: =head1 KNOWN LIMITATIONS
  575: 
  576: =over 4
  577: 
  578: =item Runtime-only
  579: 
  580: Checks are runtime only; there is no compile-time enforcement.
  581: 
  582: =item Raw coderef bypass
  583: 
  584: A raw code reference obtained B<before> wrapping (via C<can()> or direct
  585: C<\&Foo::_helper>) bypasses the check.  The attribute form prevents this
  586: because wrapping happens at compile time.
  587: 
  588: =item Moo/Moose method modifiers
  589: 
  590: Method modifiers applied after Sub::Protected has wrapped a sub will wrap
  591: the wrapper.  Apply Sub::Protected last, or use the declarative form in a
  592: C<CHECK> block after the class is fully built.
  593: 
  594: =item UNIVERSAL namespace pollution
  595: 
  596: The C<:Protected> attribute is installed in C<UNIVERSAL>, which is
  597: intentional (any package can use it after a single C<use>), but it does
  598: introduce C<UNIVERSAL::Protected> into the global namespace.
  599: 
  600: =item Thread safety
  601: 
  602: C<@_pending> and C<$BYPASS> are unguarded package globals.  Do not use
  603: concurrent C<use Sub::Protected qw(...)> calls across threads.
  604: 
  605: =back

  636: =head1 FORMAL SPECIFICATION
  637: 
  638: =head2 import
  639: 
  640: The following Z-notation schemas formally specify the state and operations
  641: of Sub::Protected.  Unicode mathematical symbols are used in this section
  642: only.
  643: 
  644:     -- Type abbreviations
  645:     Package  == seq CHAR     -- a non-empty Perl package name string
  646:     SubName  == seq CHAR     -- a Perl identifier string
  647:     Proc     == seq CHAR     -- abstract: a callable code reference
  648: 
  649:     -- Ancestry relation (derived dynamically from @ISA chains)
  650:     anc : Package -> P Package
  651:     forall p : Package .
  652:         anc p = {p} union bigcup { anc r | r in @ISA_of(p) }
  653: 
  654:     -- Protected-access predicate
  655:     permitted : Package x Package -> BOOL
  656:     forall caller, owner : Package .
  657:         permitted(caller, owner) <=> owner in anc(caller)
  658: 
  659:     -- System state
  660:     +-Registry-------------------------------------------+
  661:     | protected : P (Package x SubName)                  |
  662:     | bypass    : BOOL                                   |
  663:     | config    : { harness_bypass : BOOL }              |
  664:     +----------------------------------------------------+
  665: 
  666:     -- Initial state
  667:     +-InitRegistry---------------------------------------+
  668:     | Registry                                           |
  669:     |----------------------------------------------------|
  670:     | protected = {}                                     |
  671:     | bypass    = false                                  |
  672:     | config    = { harness_bypass |-> true }            |
  673:     +----------------------------------------------------+
  674: 
  675:     -- Wrap: add a sub to the protected registry
  676:     +-Wrap-----------------------------------------------+
  677:     | Delta-Registry                                     |
  678:     | pkg? : Package ; name? : SubName                   |
  679:     |----------------------------------------------------|
  680:     | protected' = protected union { (pkg?, name?) }     |
  681:     | bypass'    = bypass                                |
  682:     | config'    = config                                |
  683:     +----------------------------------------------------+
  684: 
  685:     -- Bypass predicate
  686:     bypass_active(R) <=>
  687:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  688: 
  689:     -- Access check: no state change
  690:     +-CheckAccess----------------------------------------+
  691:     | Xi-Registry                                        |
  692:     | caller? : Package                                  |
  693:     | owner?  : Package                                  |
  694:     | name?   : SubName                                  |
  695:     | ok!     : BOOL                                     |
  696:     |----------------------------------------------------|
  697:     | (owner?, name?) in protected                       |
  698:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  699:     +----------------------------------------------------+
  700: 
  701:     -- Violation (croak case):
  702:     --   not ok! =>
  703:     --   croak("name?()" ++ " is a protected method of " ++ owner?
  704:     --         ++ " and cannot be called from " ++ caller?)
