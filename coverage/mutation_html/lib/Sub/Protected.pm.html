  128: =head1 DESCRIPTION
  129: 
  130: Enforces Java/C++-style "protected" access at runtime: a subroutine
  131: decorated with C<:Protected> (or named in C<use Sub::Protected qw(...)>)
  132: may only be called from within its defining package or from a subclass of
  133: that package.  Any other caller causes a C<Carp::croak> with a descriptive
  134: message.
  135: 
  136: =head2 Two usage forms
  137: 
  138: =over 4
  139: 
  140: =item Attribute form (preferred)
  141: 
  142:     sub _helper :Protected { ... }
  143: 
  144: The C<:Protected> attribute is registered in C<UNIVERSAL> via
  145: L<Attribute::Handlers> when C<Sub::Protected> is loaded, so every package
  146: has access to it without any further C<use> or inheritance.  The sub is
  147: wrapped at C<CHECK> time, or, if the module is loaded after C<CHECK> (Perl
  148: 5.14 or later), at the end of the file being compiled.  This form is preferred because the protection
  149: declaration sits next to the definition and wrapping happens at compile time
  150: (making pre-wrap raw-coderef captures impossible).
  151: 
  152: =item Declarative form
  153: 
  154:     use Sub::Protected qw(_helper _other);
  155: 
  156: Each named sub is looked up in the caller's stash and wrapped at C<CHECK>
  157: time (or immediately if the module is loaded at runtime via C<require>).
  158: All named subs must be defined before C<CHECK> fires -- i.e. they must be
  159: compile-time named subs in the same file, not generated at runtime.
  160: 
  161: =back
  162: 
  163: =head2 Bypass for testing
  164: 
  165: Either condition alone (OR logic) disables all access checks:
  166: 
  167: =over 4
  168: 
  169: =item * C<$Sub::Protected::BYPASS> set to a true value.  Use C<local> in tests.
  170: 
  171: =item * C<$ENV{HARNESS_ACTIVE}> set (the convention used by L<Test::Harness>/prove).
  172: 
  173: =back
  174: 
  175: C<$Sub::Protected::BYPASS> is the recommended form for new test code;
  176: it is explicit and does not depend on the test runner.
  177: C<HARNESS_ACTIVE> is a zero-config convenience.
  178: 
  179: The HARNESS_ACTIVE bypass can be disabled by setting:
  180:

  504: =head1 KNOWN LIMITATIONS
  505: 
  506: =over 4
  507: 
  508: =item Runtime-only
  509: 
  510: Checks are runtime only; there is no compile-time enforcement.
  511: 
  512: =item Raw coderef bypass
  513: 
  514: A raw code reference obtained B<before> wrapping (via C<can()> or direct
  515: C<\&Foo::_helper>) bypasses the check.  The attribute form prevents this
  516: because wrapping happens at compile time.
  517: 
  518: =item Moo/Moose method modifiers
  519: 
  520: Method modifiers applied after Sub::Protected has wrapped a sub will wrap
  521: the wrapper.  Apply Sub::Protected last, or use the declarative form in a
  522: C<CHECK> block after the class is fully built.
  523: 
  524: =item Run-time loading on Perl < 5.14
  525: 
  526: On Perls older than 5.14, loading this module (or a package that uses it)
  527: at run time -- via C<require>, a plugin loader or a string C<eval> -- leaves
  528: the subs unprotected, because C<CHECK> has already fired.  Load it at
  529: compile time instead.
  530: 
  531: =item UNIVERSAL namespace pollution
  532: 
  533: The C<:Protected> attribute is installed in C<UNIVERSAL>, which is
  534: intentional (any package can use it after a single C<use>), but it does
  535: introduce C<UNIVERSAL::Protected> into the global namespace.
  536: 
  537: =item Thread safety
  538: 
  539: C<@_pending> and C<$BYPASS> are unguarded package globals.  Do not use
  540: concurrent C<use Sub::Protected qw(...)> calls across threads.
  541: 
  542: =back

  575: =head1 FORMAL SPECIFICATION
  576: 
  577: =head2 import
  578: 
  579: The following Z-notation schemas formally specify the state and operations
  580: of Sub::Protected.  Unicode mathematical symbols are used in this section
  581: only.
  582: 
  583:     -- Type abbreviations
  584:     Package  == seq CHAR     -- a non-empty Perl package name string
  585:     SubName  == seq CHAR     -- a Perl identifier string
  586:     Proc     == seq CHAR     -- abstract: a callable code reference
  587: 
  588:     -- Ancestry relation (derived dynamically from @ISA chains)
  589:     anc : Package -> P Package
  590:     forall p : Package .
  591:         anc p = {p} union bigcup { anc r | r in @ISA_of(p) }
  592: 
  593:     -- Protected-access predicate
  594:     permitted : Package x Package -> BOOL
  595:     forall caller, owner : Package .
  596:         permitted(caller, owner) <=> owner in anc(caller)
  597: 
  598:     -- System state
  599:     +-Registry-------------------------------------------+
  600:     | protected : P (Package x SubName)                  |
  601:     | bypass    : BOOL                                   |
  602:     | config    : { harness_bypass : BOOL }              |
  603:     +----------------------------------------------------+
  604: 
  605:     -- Initial state
  606:     +-InitRegistry---------------------------------------+
  607:     | Registry                                           |
  608:     |----------------------------------------------------|
  609:     | protected = {}                                     |
  610:     | bypass    = false                                  |
  611:     | config    = { harness_bypass |-> true }            |
  612:     +----------------------------------------------------+
  613: 
  614:     -- Wrap: add a sub to the protected registry
  615:     +-Wrap-----------------------------------------------+
  616:     | Delta-Registry                                     |
  617:     | pkg? : Package ; name? : SubName                   |
  618:     |----------------------------------------------------|
  619:     | protected' = protected union { (pkg?, name?) }     |
  620:     | bypass'    = bypass                                |
  621:     | config'    = config                                |
  622:     +----------------------------------------------------+
  623: 
  624:     -- Bypass predicate
  625:     bypass_active(R) <=>
  626:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  627: 
  628:     -- Access check: no state change
  629:     +-CheckAccess----------------------------------------+
  630:     | Xi-Registry                                        |
  631:     | caller? : Package                                  |
  632:     | owner?  : Package                                  |
  633:     | name?   : SubName                                  |
  634:     | ok!     : BOOL                                     |
  635:     |----------------------------------------------------|
  636:     | (owner?, name?) in protected                       |
  637:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  638:     +----------------------------------------------------+
  639: 
  640:     -- Violation (croak case):
  641:     --   not ok! =>
  642:     --   croak("name?()" ++ " is a protected method of " ++ owner?
  643:     --         ++ " and cannot be called from " ++ caller?)
