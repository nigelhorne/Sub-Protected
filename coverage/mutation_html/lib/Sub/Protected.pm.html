  105: 
  106: Sub::Protected - Enforce protected subroutine access (Java/C++ semantics)
  107: 
  108: =head1 VERSION
  109: 
  110: 0.03
  111: 
  112: =head1 SYNOPSIS
  113: 
  114:     package Foo;
  115:     use Sub::Protected;              # enables the :Protected attribute
  116: 
  117:     sub new { bless {}, shift }
  118: 
  119:     # Attribute form (preferred: protection lives next to the definition)
  120:     sub _helper :Protected {
  121:         ...
  122:     }
  123: 
  124:     sub public_method {
  125:         my $self = shift;
  126:         $self->_helper;              # OK -- same package
  127:     }
  128: 
  129:     # ----------------------------------------------------------------
  130: 
  131:     package Bar;
  132:     use Sub::Protected qw(_other _private);   # declarative form
  133: 
  134:     sub _other   { 'other'   }
  135:     sub _private { 'private' }
  136: 
  137: =head1 DESCRIPTION
  138: 
  139: Enforces Java/C++-style "protected" access at runtime: a subroutine
  140: decorated with C<:Protected> (or named in C<use Sub::Protected qw(...)>)
  141: may only be called from within its defining package or from a subclass of
  142: that package.  Any other caller causes a C<Carp::croak> with a descriptive
  143: message.
  144: 
  145: =head2 Two usage forms
  146: 
  147: =over 4
  148: 
  149: =item Attribute form (preferred)
  150: 
  151:     sub _helper :Protected { ... }
  152: 
  153: The C<:Protected> attribute is registered in C<UNIVERSAL> via
  154: L<Attribute::Handlers> when C<Sub::Protected> is loaded, so every package
  155: has access to it without any further C<use> or inheritance.  The sub is
  156: wrapped at C<CHECK> time, or, if the module is loaded after C<CHECK> (Perl
  157: 5.14 or later), at the end of the file being compiled.  This form is preferred because the protection
  158: declaration sits next to the definition and wrapping happens at compile time
  159: (making pre-wrap raw-coderef captures impossible).
  160: 
  161: =item Declarative form
  162: 
  163:     use Sub::Protected qw(_helper _other);
  164: 
  165: Each named sub is looked up in the caller's stash and wrapped at C<CHECK>
  166: time (or immediately if the module is loaded at runtime via C<require>).
  167: All named subs must be defined before C<CHECK> fires -- i.e. they must be
  168: compile-time named subs in the same file, not generated at runtime.
  169: 
  170: =back
  171: 
  172: =head2 Bypass for testing
  173: 
  174: Either condition alone (OR logic) disables all access checks:
  175: 
  176: =over 4
  177: 
  178: =item * C<$Sub::Protected::BYPASS> set to a true value.  Use C<local> in tests.
  179: 
  180: =item * C<$ENV{HARNESS_ACTIVE}> set (the convention used by L<Test::Harness>/prove).
  181: 
  182: =back
  183: 
  184: C<$Sub::Protected::BYPASS> is the recommended form for new test code;
  185: it is explicit and does not depend on the test runner.
  186: C<HARNESS_ACTIVE> is a zero-config convenience.
  187: 
  188: The HARNESS_ACTIVE bypass can be disabled by setting:
  189: 
  190:     $Sub::Protected::config{harness_bypass} = 0;
  191: 
  192: =head2 Configuration
  193: 
  194: The module exposes C<%Sub::Protected::config> for runtime configuration:
  195: 
  196: =over 4
  197: 
  198: =item C<harness_bypass> (default: 1)
  199: 
  200: When true, access checks are skipped whenever C<$ENV{HARNESS_ACTIVE}> is
  201: set.  Set to 0 to test protection behaviour from within a test harness.
  202: 
  203: =back
  204: 
  205: The hash is compatible with L<Object::Configure> for dependency-injection
  206: scenarios.
  207: 
  208: =head2 Error message format
  209: 
  210:     _helper() is a protected method of Foo and cannot be called from Bar
  211: 
  212: The error is raised with L<Carp/croak>, so it reports the file and line of
  213: the offending call, not a line inside Sub::Protected.
  214: 
  215: =head2 How access is decided
  216: 
  217: =over 4
  218: 
  219: =item * Only the immediate caller counts
  220: 
  221: The decision is made on the package of the code that called the protected
  222: sub.  If C<Bar::run> calls C<Foo::public>, which calls C<Foo::_helper>, the
  223: call is allowed: the immediate caller is C<Foo>.  If C<Foo::public> instead
  224: calls a C<Bar> method that calls C<Foo::_helper>, it is blocked, however
  225: deep the chain.
  226: 
  227: =item * Subclasses are allowed
  228: 
  229: A caller whose package C<isa> the owner is allowed, so calls through
  230: C<SUPER::>, C<< $self->can('_helper') >> and ordinary inherited method
  231: calls all work from a subclass.
  232: 
  233: =item * The wrapper is invisible
  234: 
  235: The wrapper hands over with C<goto &sub>, so inside the protected sub
  236: C<caller()> reports the real caller, not Sub::Protected.  Arguments
  237: (including aliasing of C<@_>), calling context (list, scalar or void) and
  238: return values, including false ones, pass through unchanged.
  239: 
  240: =back

  608: =head1 KNOWN LIMITATIONS
  609: 
  610: =over 4
  611: 
  612: =item Runtime-only
  613: 
  614: Checks are runtime only; there is no compile-time enforcement.
  615: 
  616: =item Raw coderef bypass
  617: 
  618: A raw code reference obtained B<before> wrapping (via C<can()> or direct
  619: C<\&Foo::_helper>) bypasses the check.  The attribute form prevents this
  620: because wrapping happens at compile time.
  621: 
  622: =item Moo/Moose method modifiers
  623: 
  624: Method modifiers applied after Sub::Protected has wrapped a sub will wrap
  625: the wrapper.  Apply Sub::Protected last, or use the declarative form in a
  626: C<CHECK> block after the class is fully built.
  627: 
  628: =item Run-time loading on Perl < 5.14
  629: 
  630: On Perls older than 5.14, loading this module (or a package that uses it)
  631: at run time -- via C<require>, a plugin loader or a string C<eval> -- leaves
  632: the subs unprotected, because C<CHECK> has already fired.  Load it at
  633: compile time instead.
  634: 
  635: =item UNIVERSAL namespace pollution
  636: 
  637: The C<:Protected> attribute is installed in C<UNIVERSAL>, which is
  638: intentional (any package can use it after a single C<use>), but it does
  639: introduce C<UNIVERSAL::Protected> into the global namespace.  If another
  640: module has already defined C<UNIVERSAL::Protected>, loading Sub::Protected
  641: warns that it is being replaced.
  642: 
  643: =item Thread safety
  644: 
  645: C<@_pending> and C<$BYPASS> are unguarded package globals.  Subs are
  646: normally wrapped before any thread is started, which is safe.  Calling
  647: C<< Sub::Protected->import(...) >> or loading a package that uses
  648: Sub::Protected from more than one thread at once is not supported.
  649: C<$BYPASS> is per-thread, as with any C<our> variable under ithreads.
  650: 
  651: =back

  683: =head1 FORMAL SPECIFICATION
  684: 
  685: =head2 import
  686: 
  687: The following Z-notation schemas formally specify the state and operations
  688: of Sub::Protected.  Unicode mathematical symbols are used in this section
  689: only.
  690: 
  691:     -- Type abbreviations
  692:     Package  == seq CHAR     -- a non-empty Perl package name string
  693:     SubName  == seq CHAR     -- a Perl identifier string
  694:     Proc     == seq CHAR     -- abstract: a callable code reference
  695: 
  696:     -- Ancestry relation (derived dynamically from @ISA chains)
  697:     anc : Package -> P Package
  698:     forall p : Package .
  699:         anc p = {p} union bigcup { anc r | r in @ISA_of(p) }
  700: 
  701:     -- Protected-access predicate
  702:     permitted : Package x Package -> BOOL
  703:     forall caller, owner : Package .
  704:         permitted(caller, owner) <=> owner in anc(caller)
  705: 
  706:     -- System state
  707:     +-Registry-------------------------------------------+
  708:     | protected : P (Package x SubName)                  |
  709:     | bypass    : BOOL                                   |
  710:     | config    : { harness_bypass : BOOL }              |
  711:     +----------------------------------------------------+
  712: 
  713:     -- Initial state
  714:     +-InitRegistry---------------------------------------+
  715:     | Registry                                           |
  716:     |----------------------------------------------------|
  717:     | protected = {}                                     |
  718:     | bypass    = false                                  |
  719:     | config    = { harness_bypass |-> true }            |
  720:     +----------------------------------------------------+
  721: 
  722:     -- Wrap: add a sub to the protected registry
  723:     +-Wrap-----------------------------------------------+
  724:     | Delta-Registry                                     |
  725:     | pkg? : Package ; name? : SubName                   |
  726:     |----------------------------------------------------|
  727:     | protected' = protected union { (pkg?, name?) }     |
  728:     | bypass'    = bypass                                |
  729:     | config'    = config                                |
  730:     +----------------------------------------------------+
  731: 
  732:     -- Bypass predicate
  733:     bypass_active(R) <=>
  734:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  735: 
  736:     -- Access check: no state change
  737:     +-CheckAccess----------------------------------------+
  738:     | Xi-Registry                                        |
  739:     | caller? : Package                                  |
  740:     | owner?  : Package                                  |
  741:     | name?   : SubName                                  |
  742:     | ok!     : BOOL                                     |
  743:     |----------------------------------------------------|
  744:     | (owner?, name?) in protected                       |
  745:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  746:     +----------------------------------------------------+
  747: 
  748:     -- Violation (croak case):
  749:     --   not ok! =>
  750:     --   croak("name?()" ++ " is a protected method of " ++ owner?
  751:     --         ++ " and cannot be called from " ++ caller?)
